# Flyback Converter 120VAC to 3.3VDC and Variable Output Buck-Boost Converter (March 2026)
This board has two separate converter. One is a flyback converter that converts 120VAC to 3.3V DC. The other converts 12VAC to a variable 1.2V to 5.2V output

This was a group project in my Electronics 2 class. My teammate was Mohammed Al Rabey.

- Designed PCB layout in Altium.
- Sourced all components on Digikey, and imported footprints into Altium
- Soldered surface mount components onto the PCB.
- Successfully tested circuit with 120 V AC.
